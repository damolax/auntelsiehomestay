# Design refinement v4

This pass corrects the shared design system across all routes rather than patching individual pages.

- Replaced the previous type pairing with Manrope and DM Serif Display.
- Reduced headline scale and tightened line-height.
- Added fixed content width and fluid page gutters.
- Corrected desktop, tablet and mobile grid proportions.
- Added min-width, wrapping rules and safer button behavior to prevent text overflow.
- Standardized cards, forms, imagery, CTAs, navigation and footer spacing.
- Improved mobile menu, form stacking and small-screen call-to-action behavior.
- Rebuilt the production dist folder.
